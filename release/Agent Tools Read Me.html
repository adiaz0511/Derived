Derived Agent Tools

The optional agent tools let Codex scan and prepare Xcode storage cleanup through the Derived CLI and MCP server.

Install

  1. Double-click Install Derived Agent Tools.command.
  2. Restart Codex.
  3. Run "$HOME/.local/bin/derived" --version and codex mcp get derived in Terminal.
  4. Ask Codex: Use $derived-cleanup to scan my developer storage.

The installer writes only to your user account. Administrator access is not required.

Uninstall

Double-click Uninstall Derived Agent Tools.command. Scan history and application preferences are retained.
